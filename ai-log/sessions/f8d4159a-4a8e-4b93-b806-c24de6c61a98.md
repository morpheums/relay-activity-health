The key point: Claude Code already writes every session to a JSONL transcript. That file has every prompt, every response, every tool call, and every denied tool call (like the one you rejected earlier). So "raw" is best served by exporting that file as-is, not by having hooks rebuild the conversation. The hooks' job is to make exporting automatic, and to add the parts only a person can supply: why you accepted or rejected something, and the reflection.

## Proposed design

**1. Capture (automatic, nothing edited)**
- A **Stop** hook runs after every turn and a **PreCompact** hook runs before context is compacted. Both copy the session transcript (`transcript_path` from the hook payload) into `ai-log/raw/<session_id>.jsonl`, then render a readable version at `ai-log/sessions/<date>-<session>.md` with prompts, responses and tool calls in order.
- A **SubagentStop** hook does the same for subagent transcripts, so work we hand to agents is logged too.
- A one-time **backfill** script exports *this* session. It's the planning conversation and it happens before the repo exists, but it's the best proof that we planned first.
- Very long tool output (skill text dumps, for example) gets collapsed in the markdown only. The raw JSONL stays complete, and the README will say so explicitly so it can't read as sanitizing.
