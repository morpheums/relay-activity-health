   - Only executes in Development environment (ASP.NET Core defaults to Production if `ASPNETCORE_ENVIRONMENT` is unset)

3. **`.gitignore`** already excludes `.env`, so committed-secret risk is mitigated.

4. **`TraversePath()`** does walk up the directory tree looking for a `.env`, which could pick up a `.env` from a parent directory during dev. However, this is dev-only and requires the developer to have such a file present — not an attacker-controllable surface.
